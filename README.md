# Secure Notes

A secure full-stack notes application built with Flask.

## Features
- User registration and login
- Encrypted note storage
- CSRF protection
- Login rate limiting
- Access control per user
- Audit logging
- Automated tests

## Tech Stack
- Python
- Flask
- SQLAlchemy
- bcrypt
- cryptography
- pytest

## Run Locally
```bash
pip install -r requirements.txt
python run.py
```
